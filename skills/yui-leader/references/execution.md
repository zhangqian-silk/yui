# Execution operation index

The [Leader core](../SKILL.md) permits ordinary direct work without an
execution-stage handbook. Use this index only to locate an actual operation;
do not load its targets as a bundle on activation, continuation or compaction.

- Investigation/verification design: [Implementation](implementation.md).
- Work boundaries, executor choice, dispatch material: [Allocation](work-allocation.md).
- Existing Assignment continuation/control: [Assignment](assignment-execution.md).
- Independent Review or managed-result disposition: [Review](review.md).
- Isolated Git results/conflicts: [Integration](integration.md).
- Candidate acceptance/Task completion: [Completion](completion.md).
- Meaningful working-summary changes: [Progress](task-progress.md).

Each linked manual is read in full only when its action applies. The current
Task's authority, original intent and Project requirements govern every path.
