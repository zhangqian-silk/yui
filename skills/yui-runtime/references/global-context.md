# Global input discovery

Read when the Global Context pending page needs expansion or delivery diagnostics
are relevant; receiving one exact original uses Runtime’s inbox contract directly.

Global Context `pending` is bounded current/available-input discovery, not
receipt debt or retry history; the Manifest's profile remains canonical.
Its separate `currentOriginals` contains complete small Messages correlated to
this managed Turn. Reuse the matching original; absence means use its exact read,
not no input. It neither claims nor handles the Message, and future queued or
historical bodies are not included. Read missing originals with `role message show <role> <message-id>
--json`; continue incomplete pending pages with `role message list <role>
--current --cursor <nextCursor>`. Accepted delivery retains its all-list record.
`historyCount` is missing handling evidence, not new work.

For classified delivery diagnostics, read the diagnostics section of
[Global input controls](global-input-controls.md) in its full file. That does
not authorize sending or controlling input.
