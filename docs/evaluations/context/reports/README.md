## 新增报告

使用 `YYYY-MM-DD-<topic-or-window>.md`，一份报告对应一个明确问题或相关组合，
不要为每句指导、每几KB减量生成完整实验报告。线上长时间窗可跨多个会话，
但须注明选样、版本切换、压缩/恢复边界和缺失数据。

将新报告加入本索引，标清类型和范围；若改变推荐，仅更新专题指南中的当前判断
并引用证据，不改写历史报告。无新的真实实验时明确“离线分析”，不把重读旧轨迹
计为新样本。报告不是执行授权，也不会自动触发新实验、审查或上线。
